Projects

Mbolden Change

Mbolden Change is a mission-driven nonprofit client project designed to empower grassroots movements through digital storytelling and community giving. Built with Next.js and Sanity CMS, it includes a dynamic donation portal (Stripe & Zeffy), campaign pages, and modular content blocks that allow the team to spotlight initiatives with visual and narrative clarity. The project emphasizes accessibility, clean design, and scalability, reflecting a commitment to technical excellence in service of social impact.

  • NextJs
  • Sanity CMS
  • TypeScript
  • Stripe Api

CIRCA

Circa is a quirky travel journaling app designed for the global nomad. It allows users to search, visualize, and log destinations, with relevant details like weather, and personal notes. Built with Flask and React, Circa integrates external APIs to enhance the travel logging experience, making it easy to revisit and reflect on past journeys.

MUSIC CAMP

Music Camp is a Bandcamp-inspired e-commerce platform for indie artists and fans. Users can upload albums, buy tracks, and explore curated profiles in a responsive, React-based interface. MusicCamp was built to simulate the core dynamics of digital music platforms with a focus on artist-driven content and community interaction.

RENT-A-PAD

Rent-a-Pad is a full-stack Airbnb clone built from the ground up using Flask, SQLAlchemy, and React. It includes core booking features such as listings, reviews, and reservations, with custom backend validations and dynamic frontend interactions. It showcases the ability to replicate complex platform logic while applying best practices in both frontend architecture and RESTful API design.
